三学习路线建议

社招 Java 后端（约 3 个月）

  1. 第 1~4 周：01~04（语言 + 并发 + JVM + Spring）刷面经 + 05 算法每天 2 题
  2. 第 5~6 周：06（数据库）+ 10~11（微服务 + Kafka）
  3. 第 7~10 周：07-LLD 33 题（每天 1 题精做）
  4. 第 11~12 周：08-HLD 挑 20 道精做 + 16 行为面建故事库

校招 / 1~3 年经验

05 算法权重最高，07-LLD 优先于 08-HLD，HLD 掌握高频 15 题即可。

AI 方向（Java + AI）

在社招路线上，把 14（AI 工程）+ 15（ML 系统设计）替换部分 HLD 时间；RAG / Agent / MCP 是当前热点。

每日节奏：算法 2 题（05）保持手感 + 一个知识板块推进一个章节。
